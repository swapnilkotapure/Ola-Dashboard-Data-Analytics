# 🚖 Ola Booking Dashboard | Power BI Project

## 📌 Project Overview

The Ola Booking Dashboard is an interactive Power BI project developed to analyze booking trends, customer behavior, ride performance, and revenue insights. The dashboard helps stakeholders monitor business performance through dynamic visualizations and key performance indicators (KPIs).

This project demonstrates end-to-end data analysis using Power BI, including data cleaning, transformation, DAX calculations, and dashboard development.

---

## 🎯 Project Objectives

- Analyze overall ride bookings
- Monitor booking status (Completed, Cancelled, Pending)
- Track revenue and ride performance
- Identify peak booking periods
- Analyze payment methods
- Evaluate customer and driver ratings
- Support business decisions through interactive dashboards
